# TaskForge 🚀

**A modern, responsive task and project management application built with React, Redux Toolkit, and Tailwind CSS.**

TaskForge helps individuals and teams organize projects, manage tasks, track progress, and stay productive through a clean and responsive interface.

## ✨ Features

- 📊 **Dashboard** — View task statistics, recent tasks, project progress, and activity.
- ✅ **Task Management** — Create, edit, view, and delete tasks.
- 📁 **Project Management** — Create, update, and delete projects.
- 🏷️ **Task Priorities** — Organize tasks by Low, Medium, High, and Urgent priorities.
- 🔄 **Task Status Tracking** — Manage tasks across Todo, In Progress, Review, and Done.
- 🔍 **Search & Filters** — Find tasks using search, project, status, and priority filters.
- 📅 **Due Dates** — Track deadlines and manage upcoming work.
- 👥 **Team Assignments** — Assign tasks to team members
